# NoGatekeepers Index

**Don't just criticize lock-in. Measure the exit door.**

An evidence-backed public index comparing digital platforms and independent alternatives on user control, portability, interoperability, transparency, governance, and practical exit costs.

## Mission
Help people understand where control is concentrated and which alternatives provide meaningful choice. This is not a hit list, pay-to-rank directory, or claim of malicious intent.

## Evaluation dimensions
- Data export: completeness, format, machine readability, fees.
- Interoperability: open protocols, documented APIs, third-party clients.
- Identity portability: migration and user-controlled identity.
- Governance: decision transparency, appeals, concentration.
- Operational independence: local/self-hosted operation and provider diversity.
- Switching costs: time, money, lost features, migration friction.
- Accessibility and usability.
- Security and privacy: published practices, limitations, incident transparency.

## Evidence rules
Every claim needs a dated source, retrieval date, scope, and confidence. Separate direct observation, vendor statement, independent evaluation, and user report. Unknown stays unknown. Publish corrections and methodology.
